# Git Branch Protection Runbook

Status: PHASE-1_SKELETON
Phase: Phase -1 Governance Bootstrap

Recommended main branch rules:

- Require pull request before merging.
- Require status checks to pass.
- Require conversation resolution.
- Require linear history.
- Disallow force pushes.
- Disallow deletions.
- Require CODEOWNERS review.

@owner must be replaced by the actual GitHub username or team before branch protection is enforced.

If Codex has no GitHub admin permissions, do not attempt to configure branch protection. Record pending manual owner action.
