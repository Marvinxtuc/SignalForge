## Summary

SignalForge v0.1.0 MVP is a local, Docker Compose based MVP for finding product opportunity signals from collected platform content. The release validates the end-to-end local/mock flow:

```text
raw_items -> signals -> embeddings -> clusters -> opportunities -> Signal Inbox
```

This release is ready for owner review and release freeze after Phase 7 validation. It is not a production deployment and does not claim real-platform smoke acceptance.

## Included

- Governance, docs-as-code, no-secrets checks, and phase gates.
- Docker Compose local runtime for API, web, PostgreSQL with pgvector, and Redis.
- Phase 1 data model, Alembic migration, seed data, and migration/data validators.
- Phase 2 backend API for projects, keywords, jobs/logs, signals, clusters, opportunities, settings, and reports.
- Phase 3 connector abstraction with mock and disabled connectors.
- Phase 4 Reddit and Product Hunt P0 connector implementation with mocked CI coverage and safe degradation.
- Phase 5 Processing Pipeline with cleaning, redaction, fallback classification, mock embeddings, clustering, opportunity scoring, and Signal Quality Gate.
- Phase 6 Frontend MVP with Signal Inbox, Dashboard, Opportunity Board, Logs, Settings, and Reports.
- Markdown and CSV report export paths that preserve source URLs.
- Rollback runbook, tag checklist, branch protection guidance, and PR checklist.
