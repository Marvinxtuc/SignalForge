# Triage Labels

Status: local Markdown pilot.

These roles are local draft metadata only. Do not apply labels in GitHub or another tracker
without explicit owner approval.

## Category roles

- `bug` - broken behavior or regression.
- `enhancement` - new capability or improvement.

## State roles

- `needs-triage` - owner evaluation needed.
- `needs-info` - waiting for more evidence or reporter detail.
- `ready-for-agent` - specified enough for AFK agent work after approval.
- `ready-for-human` - requires owner judgment, credentials, manual checks, or high-risk action.
- `wontfix` - not actioned; requires explicit owner decision.

Every triage draft should include exactly one category role and one state role.
