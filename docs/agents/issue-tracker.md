# Issue Tracker

Status: local Markdown pilot.

SignalForge Hermes/Codex skills must not publish GitHub Issues or write to any external issue
tracker during the pilot.

Use local Markdown drafts under `docs/agents/drafts/` for:

- PRDs from `hermes-to-prd`
- Vertical issue slices from `hermes-to-issues`
- Triage notes and agent briefs from `hermes-triage`

External tracker publication, labels, comments, and closes require a separate explicit approval.

## Draft naming

Use short kebab-case names with a date prefix when creating approved local drafts:

- `YYYY-MM-DD-prd-<topic>.md`
- `YYYY-MM-DD-issue-<topic>.md`
- `YYYY-MM-DD-triage-<topic>.md`
- `YYYY-MM-DD-agent-brief-<topic>.md`
