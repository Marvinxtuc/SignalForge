# Security and Token Audit

Status: PHASE-1_SKELETON
Phase: Phase -1 Governance Bootstrap

Security rules:

- No real token in repo.
- `.env` must not be committed.
- `.env.example` contains only empty values.
- CI does not require real platform tokens.
- Real platform acceptance is local/manual acceptance.
- Product Hunt permission limits can degrade safely with readable logs.

Phase -1 does not represent final MVP acceptance.
